## GOAL
Transport layer for D13 bridge (docs/research/S1-gpu-bridge.md): per-thread SPSC shm ring (memfd) + futex/eventfd wakeup, control socket passing fds via SCM_RIGHTS. No Vulkan yet.
## STEPS
- native/vk-bridge/transport/{ring.h,ring.c,sock.c,sock.h}: ring create (memfd 1MiB default), push/pop variable-length msgs w/ wraparound, blocking wait; sock: send/recv msg + up to 4 fds.
- native/vk-bridge/test/transport_test.c: fork server/client; client sends 100k msgs of random sizes (1..64KiB, deterministic seed) -> server echoes checksum; also sends a memfd via SCM_RIGHTS, server writes pattern, client verifies. Print `TRANSPORT ok msgs=N`, `FDPASS ok`, `LAT_US p50=.. p99=..` (64B roundtrip).
- Build host (gcc -Wall -Werror) and android arm64 (NDK clang, aarch64-linux-android29, static-ish); script native/vk-bridge/build-transport.sh runs host test, then adb push+run on phone (/data/local/tmp/lodos).
## OUTPUT
files above. NOTES: host+phone latency/throughput numbers.
