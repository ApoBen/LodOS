Check if an in-process wrapper ICD (no socket, guest glibc process dlopens Android's Vulkan driver through a bionic linker shim, as used in Winlator/GameNative forks and Termux mesa-vulkan-icd-wrapper) works rootless under proot on Mali-G720 and beats our socket vk-bridge.
## STEPS
1. Find the open-source wrapper (identify repo + license; prefer MIT/GPL-compatible; record in json license). Reuse our T019 glibc<->bionic boundary work where possible.
2. Build for the phone trixie guest, run vkcube (headless/offscreen ok) + zink eglgears; measure fps.
3. Measure our vk-bridge vkcube fps the same way (scripts/guest-vkbridge-test.sh). Note proot/ptrace or SELinux blockers exactly.
