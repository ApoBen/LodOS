## GOAL
Replace the ad-hoc start sequence in scripts/pc-phosh-session.sh with native/lodos-init (D3) as the guest PID1, on PC. This proves the init design before the phone port.
## STEPS
1. Build lodos-init x86_64 musl (scripts/build-init.sh) and copy it into the PC guest rootfs at /sbin/lodos-init. Do not overwrite /sbin/init.
2. Write the guest unit/config files that lodos-init reads (check native/lodos-init/src for the format). Order: dbus system bus -> elogind -> lodos-wl must already run on the host -> phoc (WAYLAND_DISPLAY=nested, pixman, phoc.ini from T037) -> phosh. Install them via a new scripts/pc-guest-init.sh.
3. Add mode `init-phosh` to scripts/pc-desktop.sh: start lodos-wl headless, then `proot ... /sbin/lodos-init`, wait, dump docs/screens/T045-init-phosh.png, then send lodos-init its shutdown signal. All guest procs must exit cleanly (check with pgrep), with no orphans left.
4. If a lodos-init bug blocks this, fix it in native/lodos-init with a cargo test. Keep the 16 existing tests passing.
5. Append a section to docs/research/S2-pc-desktop.md: boot log excerpt, timings.
