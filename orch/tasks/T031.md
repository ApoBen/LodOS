## GOAL
native/lodos-init (Rust): PID-1-ish supervisor for the proot guest (D3): starts dbus, elogind, then units; plus `systemctl` shim CLI talking to it over a unix socket.
## STEPS
- Parse subset of systemd .service files: [Unit] Description/After/Requires/Wants, [Service] Type=simple|forking|oneshot|dbus|notify(treat as simple), ExecStart/ExecStartPre/ExecStop, Environment/EnvironmentFile, User, Restart=on-failure|always, WorkingDirectory. [Install] WantedBy. Search /etc/systemd/system, /lib/systemd/system, /usr/lib/systemd/system (root configurable for tests).
- Supervisor: dependency order (topo sort, cycle error), restart w/ backoff, reap zombies, SIGTERM shutdown in reverse order, log to /var/log/lodos-init.log.
- systemctl shim: start|stop|restart|status|is-active|enable|disable|list-units|daemon-reload; exit codes compatible with systemctl (is-active 0/3).
- cargo test on x86_64 with temp dir unit fixtures (spawn /bin/sleep, /bin/true, a crashing unit for restart); cross build aarch64 via scripts/build-rs.sh.
## OUTPUT
native/lodos-init/ (bins: lodos-init, systemctl), tests, NOTES.
