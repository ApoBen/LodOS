## GOAL
USER DIRECTIVE: second app icon "Linux Terminal" in the launcher. It opens a native terminal straight into the Debian guest shell, independent of lodos-wl/phosh. Useful as a lite-mode default, a rescue shell and a fast CLI.
## STEPS
1. Dependencies: com.termux terminal-view + terminal-emulator (pinned git tag via JitPack, or vendored source with LICENSE). These are libraries only; the Termux app is NOT required. Add them to THIRD_PARTY.md (name, version, Apache-2.0).
2. org.lodos.app.terminal.TerminalActivity plus an <activity-alias> (or activity) with its own MAIN/LAUNCHER, label "Linux Terminal" and a distinct icon (adaptive vector, terminal glyph). Opening it must not start DisplayActivity or phosh.
3. Spawn the guest shell in a PTY (terminal-emulator JNI createSubprocess): proot argv/env from GuestLaunch (T046), with lite-mode env when active and a login bash in the guest (/bin/bash -l, TERM=xterm-256color, HOME=/root, TZ taken from the Android timezone). Works if the rootfs is missing: show "Setup not done -> open LodOS" plus a button to SetupActivity.
4. UX: extra keys row (Esc, Tab, Ctrl, Alt, arrows, |, -, /), pinch font size, copy/paste, keep the session while the activity is recreated (rotation). Multiple sessions are optional.
5. Pure-Kotlin TerminalLaunchSpec (rootfs present/missing, lite on/off, TZ -> argv/env) with >=6 JVM tests in src/test/.../terminal/TerminalLaunchSpecTest.kt.
6. Phone smoke (scripts/phone-terminal-smoke.sh): install the debug APK, rootfs via scripts/phone-app-rootfs.sh if needed, `am start` the terminal component, `input text 'cat /etc/debian_version'` + enter, wait, `screencap` -> docs/screens/T057-terminal.png (the debian version must be visible), then force-stop.
## OUTPUT
assembleDebug + tests pass, PNG, 3-line note in docs/research/guest-session.md. Phone rules in GEMINI.md apply.
