## GOAL
Make native/lodos-wl runnable/testable on x86_64 Linux without Android (headless backend: composite into an in-memory RGBA buffer), so protocol work can progress while phone is offline.
## STEPS
- Cargo feature/cfg: android backend (existing JNI/SurfaceView) vs `headless` backend (x86_64). Keep Android build intact (scripts/build-rs.sh native/lodos-wl must still build).
- Headless: socket in $XDG_RUNTIME_DIR (path), compose committed wl_shm buffers of toplevels into framebuffer; debug hook to dump framebuffer as PPM (env LODOS_WL_DUMP=path on SIGUSR1 or after N frames).
- Advertise + handle: wl_compositor, wl_shm (ARGB/XRGB8888), xdg_wm_base (configure/ack, ping/pong), wl_seat w/ pointer+touch+keyboard (synthetic injection API used by tests), wl_output.
- Integration test (cargo test) with wayland-client crate test client: connect, create xdg_toplevel, ack configure, attach 64x64 solid green shm buffer, commit; assert framebuffer pixel green; inject touch down/up and assert client receives wl_touch events.
- If `wayland-info` installed on PC, also run it against headless server in test script (optional).
## OUTPUT
native/lodos-wl changes, tests, NOTES.
