## GOAL
Turn the T068 FSR1 core (native/lodos-fg/src/fsr1_core.*) into a Vulkan layer "VK_LAYER_LODOS_fg" (gamescope-style). The app sees a smaller swapchain extent; at vkQueuePresentKHR the layer runs EASU+RCAS into the real swapchain image. Reuse-first: copy the dispatch-table/layer skeleton from vkBasalt (zlib) or the Khronos sample layer. Note the origin in native/lodos-fg/README.md.
## STEPS
1. native/lodos-fg/src/layer.c + lodos_fg.json manifest (enable via env LODOS_FG=1; VK_LAYER_PATH to build dir). Env vars: LODOS_FG_PRESET=quality|balanced|performance (1.5/1.7/2.0 from the presets header), LODOS_FG_SHARPNESS (default 0.2).
2. Hook vkGetPhysicalDeviceSurfaceCapabilitiesKHR (scale currentExtent/maxImageExtent down), vkCreateSwapchainKHR (real swapchain at full size + app-facing VkImages at reduced size), vkGetSwapchainImagesKHR (return the app-facing images), vkAcquireNextImageKHR and vkQueuePresentKHR (wait on the app semaphores, record FSR1 from app image to real image with layout transitions, signal, present real). Full-res passthrough when LODOS_FG is unset.
3. Debug: LODOS_FG_DUMP=<path.png> + LODOS_FG_DUMP_FRAME=N dumps the upscaled real image once.
4. test/present_headless.c: VK_EXT_headless_surface swapchain at 1280x720, render a synthetic checker/diagonal pattern into whatever extent the app sees, present 30 frames. Print `app extent WxH`.
5. Run it with the layer at the balanced preset: app extent must be about 753x424; the dump must be a 1280x720 PNG, not black. Print `LODOS_FG layer ok`. Copy the dump to docs/screens/T069-layer.png.
6. Do not hook any compositor or display server. Headless surface only.
## OUTPUT
build/lodos-fg/liblodos_fg.so + manifest, test passes on Intel Arc, PNG, README section "layer usage".
