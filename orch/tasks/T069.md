## STEPS
1. Current layer.c segfaults: infinite recursion vkEnumeratePhysicalDevices <-> libVkLayer_MESA_device_select.so (gdb, review31). Causes: single global next_gipa (not per instance), GIPA forwards every name, pfnGetPhysicalDeviceProcAddr set to GIPA. Fix: per-instance and per-device dispatch tables keyed by the loader dispatch pointer (*(void**)handle), intercept vkCreateInstance/vkDestroyInstance/vkCreateDevice/vkDestroyDevice (advance chain for both), vkGetInstanceProcAddr/vkGetDeviceProcAddr, set pfnGetPhysicalDeviceProcAddr=NULL (or a real one returning NULL for unknown names). 2. Hook vkGetPhysicalDeviceSurfaceCapabilitiesKHR (+ ...2KHR): when LODOS_FG=1|true|yes, scale currentExtent/maxImageExtent by preset (quality 1.5, balanced 1.7, performance 2.0); clamp >= minImageExtent. 3. test/present_headless.c: VK_EXT_headless_surface, request 1280x720 (headless currentExtent is 0xFFFFFFFF -> use maxImageExtent clamped to 1280x720 so scaling is visible), create swapchain, clear each image to a pattern, present 30 frames, print `app extent WxH` and `presented 30`. Exit 0.
