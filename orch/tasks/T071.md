## GOAL
On top of the working T069 layer skeleton: the app renders into reduced-size layer-owned images; at present the layer runs the T068 FSR1 core (native/lodos-fg/src/fsr1_core.*) into the real full-size swapchain image.
## STEPS
1. vkCreateSwapchainKHR: create the real swapchain at full surface size (add TRANSFER_DST/STORAGE usage as needed, check support) + N app-facing VkImages (+memory) at the scaled extent with the app's format/usage. vkGetSwapchainImagesKHR returns app-facing images. vkDestroySwapchainKHR frees all.
2. vkAcquireNextImageKHR: acquire real image, return same index. vkQueuePresentKHR: per image a command buffer: wait app semaphores, barriers, EASU+RCAS (LODOS_FG_SHARPNESS default 0.2) app image -> real image, transition to PRESENT_SRC, signal own semaphore, present real swapchain. Needs a device dispatch for queue/cmd functions (T069 tables).
3. LODOS_FG_DUMP=<png> + LODOS_FG_DUMP_FRAME=N: copy real image to host buffer once, write PNG (stb_image_write or own zlib-free stored PNG).
4. present_headless must render a visible checker/diagonal pattern (not just black) so the dump is non-black.
5. Accept runs in runner on Intel Arc (sandbox may lack GPU, R27). Copy dump to docs/screens/T071-layer.png.
