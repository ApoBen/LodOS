## GOAL
Wizard (T030) only has FakeRootfsRepo. Implement the real one so first run can download + extract the Debian rootfs at app uid (extract via existing native/lodos-rootfs JNI, T026/T033).
## STEPS
- android/app/src/main/java/org/lodos/app/setup/HttpRootfsRepo.kt implements RootfsRepo: HttpURLConnection download to cacheDir with resume (Range) + progress + cancel; streaming sha256 verify; extract via existing lodos-rootfs JNI binding (find it with grep -r lodos_rootfs android/); isInstalled = files/rootfs/etc/debian_version exists.
- Rootfs URL+sha256 from a small JSON manifest (assets/rootfs-manifest.json, arch arm64/x86_64) — placeholder URL OK, documented.
- SetupActivity uses HttpRootfsRepo by default; FakeRootfsRepo only behind a debug intent extra `fake_repo=1`.
