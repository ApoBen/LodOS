## GOAL

## STEPS
- Start lodos-wl headless (T034) on host, size 720x1600, socket in $XDG_RUNTIME_DIR.
- In PC guest (scripts/pc-guest.sh): WAYLAND_DISPLAY=/run/host-xdg/<sock> WLR_BACKENDS=wayland WLR_RENDERER=pixman WLR_NO_HARDWARE_CURSORS=1 phoc -E foot (or phoc with config; no phosh yet).
- Implement whatever lodos-wl protocols phoc/wlroots wayland backend requires and are missing (wl_compositor v4+, wl_subcompositor, xdg_wm_base, wl_shm, wl_seat, wl_output, xdg-decoration stub, wp_presentation/viewporter if required; linux-dmabuf NOT needed with pixman). Log missing-global errors from phoc to find gaps.
