T016 found elogind uninstallable (Conflicts systemd via dbus-user-session). Make guest systemd-free per D3 so phosh gets org.freedesktop.login1 + system bus.
## STEPS
- scripts/guest-init.sh = HOST-side driver like scripts/guest-phosh.sh (pushes + runs via phone-run.sh, idempotent): apt install sysvinit-core (or equivs dummy `systemd` provider if needed) then elogind libpam-elogind dbus-x11; replace dbus-user-session with dbus-x11 if conflict. - System bus: start `dbus-daemon --system` with system.conf diverted to abstract socket (same trick as T016 session.conf, or rely on native/unix2abstract LD_PRELOAD); export DBUS_SYSTEM_BUS_ADDRESS accordingly.

- Re-run phosh 10s inside headless phoc (scripts/guest-phosh.sh path) and count 'login1' warnings; print `INIT phosh-login1-warn=<n>`.
- Append findings to docs/research/S3-phosh-guest.md (### elogind section).
