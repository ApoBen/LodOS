## GOAL
A user-facing settings screen so lite mode (T044/T053) and the lodos-fg upscale preset (T068/T069) can be chosen in the app, persisted, and passed to the guest.
## STEPS
1. android/app/src/main/java/org/lodos/app/settings/: LodosSettings (SharedPreferences wrapper; keys: lite_mode = auto|on|off, fg_preset = off|quality|balanced|performance, fg_sharpness float 0..1 default 0.2) + SettingsActivity (plain Android views or PreferenceFragmentCompat, whichever is already a dependency; no new heavy libs). Register it in the manifest and open it from a MainActivity/SetupActivity button.
2. Pure function SettingsEnv.toEnv(settings, liteTier): Map<String,String>. fg off -> no LODOS_FG keys. Otherwise LODOS_FG=1, LODOS_FG_PRESET, LODOS_FG_SHARPNESS. lite on/auto(tier lite) -> the existing lite env from the lite/ pkg.
3. Wire it into GuestLaunch env building (existing lite wiring from T053: replace/extend it, don't duplicate it).
4. JVM tests: settings/SettingsEnvTest (>=5 cases: defaults, fg off, each preset, sharpness clamp, lite on/off/auto) + GuestLaunch test asserting the env contains LODOS_FG when set.
## OUTPUT
Tests pass, assembleDebug ok. Short note in docs/research/ (existing P1 doc) on the settings keys.
