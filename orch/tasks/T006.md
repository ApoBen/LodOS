## GOAL
D4 groundwork: proot binary + loader built from source with orch/env.sh NDK, runnable from adb shell (no APK install needed).
## STEPS
- Sources into third_party/src/ (gitignored): termux/proot (GPL-2.0) + talloc (static). Pin commits; record in THIRD_PARTY.md (name, url, commit, license).
- scripts/build-proot.sh: cross-compile for aarch64-linux-android29 with NDK clang; static talloc; produce build/proot/arm64/libproot.so (the proot exe, named lib*.so for APK packaging) and build/proot/arm64/libproot-loader.so (loader). Use termux build recipe as reference (PROOT_UNBUNDLE_LOADER etc).
- Test on phone: adb push to /data/local/tmp/lodos/proot/, chmod +x, run `PROOT_LOADER=.../libproot-loader.so PROOT_TMP_DIR=/data/local/tmp/lodos/tmp ./libproot.so -0 /system/bin/id` (host fs, fake root).
## OUTPUT
scripts/build-proot.sh, THIRD_PARTY.md entries; NOTES: commits, flags, phone output.
