## GOAL
USER pre-release requirement (a): one button collects logs + device info into a shareable file and prefilled GitHub issue body.
## STEPS
- android/app: `BugReport` (Kotlin, pure-JVM core testable): collects device info (Build.MODEL/MANUFACTURER/SOC_MODEL, SDK, ABI, RAM, page size, GPU renderer string if available, app versionName), app logcat (own pid only, `logcat -d --pid`), files under <filesDir>/logs/*.log (cap each 512KB, tail), setup state; redacts home paths/emails/tokens (regex) -> writes <cacheDir>/bugreport-<ts>.zip with report.md + logs/.
- Share via FileProvider ACTION_SEND; second action opens browser to issue URL with title/body (body = report.md summary <6KB, URL-encoded; repo URL constant placeholder).
- Add "Report a problem" button to SetupActivity (and a menu item for future main activity).
- JVM unit tests: zip contents, size caps, redaction (email/token removed), body length cap.
## OUTPUT
BugReport.kt + tests, FileProvider in manifest, NOTES.
