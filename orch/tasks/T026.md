## GOAL
T020 cold extract of trixie tar.gz at app uid took 198.8s (proot tar, link2symlink). Make first-run install fast; target total cold extract <60s on P1.
## STEPS
- Measure first: where is time (gzip decode vs proot syscall overhead vs link2symlink). Log in NOTES.
- Implement extraction natively in app process (no proot): Rust (D11, cargo-ndk, crates tar+flate2 w/ zlib-rs or libdeflate; or zstd if repackaging tarball to .tar.zst is faster — fetch-side recompress allowed) via JNI from ProbeActivity probe=rootfs. Must preserve: symlinks, hardlinks (emulate as proot link2symlink expects, or copy), modes, dirs; record uid/gid/dev nodes skipped (proot -0 fakes root).
- Extract into fresh <filesDir>/rootfs2 (keep old rootfs), then run the same T020 proot checks (debian_version, apt-install hello, hello) against rootfs2.
- Log `RFS extract ok native <ms>` and existing RFS lines; reuse scripts/phone-app-rootfs.sh with a flag (e.g. ROOTFS=rootfs2 FRESH=1) that deletes rootfs2 first so cold path is always measured.
## OUTPUT
native/<crate>/, app JNI glue, scripts/phone-app-rootfs.sh flag, NOTES timings.
