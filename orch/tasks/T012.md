## GOAL
First brick of lodos-vk-bridge (D13, docs/research/S1-gpu-bridge.md §3 "vk.xml-Generated Bridge"). Python generator reads Khronos vk.xml and emits C encode/decode for a small command subset. Host-only (no phone).
## STEPS
- git clone --depth 1 --branch v1.4.<latest> https://github.com/KhronosGroup/Vulkan-Headers third_party/src/Vulkan-Headers (pin tag in THIRD_PARTY.md; do not commit the clone if third_party/src is gitignored — check .gitignore).
- native/vk-bridge/gen/gen.py (python3 stdlib only, xml.etree): input vk.xml + list file native/vk-bridge/gen/cmds.txt. Output dir arg -> vkb_cmds.h (enum VKB_CMD_*, one per cmd), vkb_marshal.c/.h: per cmd `size_t vkb_enc_<cmd>(uint8_t*buf, ...params)` and `vkb_dec_<cmd>(const uint8_t*, ...out)`. Handle: scalars, handles (as uint64), enums/flags, pointers-to-struct with pNext=NULL only (pNext chains -> TODO, assert), fixed arrays, len-annotated arrays (count member), char* strings. Skip unsupported params with a generated #error-free stub + comment listing why.
- cmds.txt v0: vkCreateInstance, vkEnumeratePhysicalDevices, vkGetPhysicalDeviceProperties, vkGetPhysicalDeviceFeatures, vkGetPhysicalDeviceQueueFamilyProperties, vkCreateDevice, vkGetDeviceQueue, vkAllocateMemory, vkCreateBuffer, vkDestroyBuffer.
- native/vk-bridge/test/roundtrip.c: for each cmd fill params with fixed pattern, encode, decode, memcmp/deep-compare; print `ROUNDTRIP <cmd> ok` per cmd and final `ROUNDTRIP_ALL ok n=<N>`.
- native/vk-bridge/build-host.sh: run gen.py -> build/vk-bridge/gen/, gcc -Wall -Werror -I Vulkan-Headers/include, run test.
## OUTPUT
native/vk-bridge/{gen/gen.py,gen/cmds.txt,test/roundtrip.c,build-host.sh}, THIRD_PARTY.md. NOTES: supported param kinds, known gaps (pNext, unions, handles mapping).
