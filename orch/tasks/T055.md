## GOAL
Check if Mesa Venus (virtio-gpu Vulkan protocol) over virglrenderer's vtest socket can replace/augment our vk-bridge on Mali-G720.
## STEPS
1. Cross-build virglrenderer (pinned tag, -Dvenus=true, vtest) for aarch64-linux-android with NDK; it must load Android /system/lib64/libvulkan.so. Note which Venus-required host extensions Mali lacks (see docs/research/mali-g720-vk.json: external_memory_fd/dma_buf, etc.).
2. In phone trixie guest build/install Mesa with -Dvulkan-drivers=virtio (venus) -Dgallium-drivers=zink; run with VN_DEBUG=vtest and the vtest socket (use native/unix2abstract as needed, as in T043).
3. Run vkcube (headless/offscreen ok) and zink glxgears/eglgears; measure fps. Measure our vk-bridge vkcube fps the same way (scripts/guest-vkbridge-test.sh).
