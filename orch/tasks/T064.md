## GOAL
GuestLaunch already supports `sdcard` bind (null = none) but nothing sets it. Add the user-facing flow.
## STEPS
1. New `android/app/src/main/java/org/lodos/app/storage/StorageAccess.kt`: pure-Kotlin decision logic (sdk int + granted flags -> state NONE/GRANTED/NEEDS_REQUEST, which intent/permission to request: API30+ MANAGE_EXTERNAL_STORAGE via Settings.ACTION_MANAGE_APP_ALL_FILES_ACCESS_PERMISSION, else READ/WRITE_EXTERNAL_STORAGE) + `sdcardPathOrNull(state, externalDir)`.
2. Manifest: MANAGE_EXTERNAL_STORAGE (tools:ignore ScopedStorage) + READ/WRITE_EXTERNAL_STORAGE maxSdkVersion=32.
3. Session UI (where Start lives, T052): small "Allow /sdcard" button shown when NEEDS_REQUEST; the launch path passes `sdcard = Environment.getExternalStorageDirectory().path` only when GRANTED.
4. JVM tests `StorageAccessTest` >=5 cases (api29/30/34, granted/denied, path null when denied). Do not change GuestLaunch arg format (its 14 tests must stay green).
## OUTPUT
tests + build pass; one line in docs/research/P1-setup.md.
