## GOAL
Re-verify shell-uid findings at app uid (R8, R10, T013 KEY FINDING: path AF_UNIX bind EACCES at shell uid). D4: binaries shipped as lib*.so in APK, exec'd from nativeLibraryDir.
## STEPS
- Copy build outputs into android/app/src/main/jniLibs/arm64-v8a/: proot -> libproot.so, proot loader -> libproot_loader.so (if separate), lodos-wl -> liblodos_wl.so. Set `android:extractNativeLibs="true"` (or packaging.jniLibs.useLegacyPackaging=true) so files exist on disk. Script: scripts/stage-jnilibs.sh (copies from build/, fails if missing).
- Kotlin: org.lodos.app.ProbeActivity (exported=false is ok; start via `adb shell am start -n org.lodos.app/.ProbeActivity`) -> runs on background thread, logs with tag LODOS_PROBE:
  1. `uid=<Process.myUid()>`
  2. start liblodos_wl.so with socket path `<filesDir>/run/wayland-0` (mkdir run); after 1s check socket file exists -> `PATHSOCK ok` / `PATHSOCK fail <stderr tail>`; kill it.
  3. run `libproot.so -0 /system/bin/id` (PROOT_LOADER=<nativeLibDir>/libproot_loader.so, PROOT_TMP_DIR=<cacheDir>) -> `PROOT ok <stdout>` / `PROOT fail rc=<n> <stderr tail>`.
  4. `PROBE_DONE`.
- scripts/phone-app-probe.sh: stage-jnilibs, ./gradlew assembleDebug (android/), adb install -r, logcat -c, am start, wait up to 30s for PROBE_DONE, print `logcat -d -s LODOS_PROBE`.
- If adb install blocked by HyperOS (R7): print NEEDS_USER_INSTALL + apk path, exit 2; note in NOTES.
## OUTPUT
